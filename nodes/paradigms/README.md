A paradigm is a style of programming with its own model of what a program is. This area describes each main style, the ideas that define it and the languages that support it. A language often supports more than one style.

## What it holds

- Imperative programming: programs as a sequence of commands that change state.
- Procedural programming: imperative programs split into procedures that call each other.
- Structured programming: control flow from sequence, selection and iteration only, without arbitrary jumps.
- Object-oriented programming: programs as objects that hold state and answer messages.
- Functional programming: programs as the composition of functions, with values that do not change.
- Logic programming: programs as facts and rules, and a run as a search for a proof.
- Declarative programming: programs that state the result and leave the steps to the system.
- Dataflow and reactive programming: programs as a graph of values that update when their inputs change.
- Array programming: operations on whole arrays at once, as in APL and NumPy.
- Concatenative programming: programs as the composition of functions on a stack, as in Forth.
- Event-driven programming: programs that wait for events and run a handler for each one.
- Aspect-oriented programming: code for a cross-cutting concern, such as logging, kept apart and woven in.
- The actor model: actors that send messages and keep private state, as the way to structure a whole program.
- Multi-paradigm design: how a language combines styles, and how to choose a style for a part of a program.

## What it does not hold

- The detail of each construct, such as closures or classes. Each has its own area, such as [Functions and abstraction](/functions-and-abstraction/) and [Objects and classes](/objects-and-classes/). A paradigm page links to them.
- Actor runtimes and libraries as tools for concurrent programs. They are in [Concurrency and parallelism](/concurrency-and-parallelism/).
- Array libraries for data work, such as NumPy as a tool. They are in [Data science and ML programming](/data-science-and-ml-programming/).
