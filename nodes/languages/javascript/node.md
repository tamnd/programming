## Overview

JavaScript is the language that the standard ECMA-262 defines under the name ECMAScript. The standard calls it an object-oriented programming language "for performing computations and manipulating computational objects within a host environment".[^1] It was first a scripting language, and the standard now calls it "a fully featured general-purpose programming language".[^1]

The standard has no provisions for input or output. The host environment supplies them.[^1] A web browser is one host. It gives objects for windows, menus, dialog boxes and input and output, and it attaches scripts to events. The scripts react to the user, so there is "no need for a main program".[^2] A server runtime such as Node.js is another host.[^3]

Brendan Eich designed and implemented the language at Netscape in May 1995. Its first purpose was to put small pieces of code in Web pages.[^4] The management of Sun and Netscape required that it "look like Java". Eich took a prototype-based object model from Self, and he used first-class functions for idioms from Scheme.[^4]

The standard describes the language as object-based. A program is a cluster of communicating objects.[^5] The Ecma technical committee TC39 develops the standard, and an edition comes out each year.[^6]

## A first program

```javascript run id=hello
console.log("Hello, world!");
```

```output for=hello
Hello, world!
```

The program below groups a list of orders by item and prints the total of each group. It uses object literals, destructuring, arrow functions, `Object.groupBy` and a template literal. Then an `async` function computes the grand total with `await` and `Promise.all`.

```javascript run id=orders
const orders = [
  { item: "tea", qty: 2, price: 3.5 },
  { item: "cake", qty: 1, price: 4.25 },
  { item: "tea", qty: 1, price: 3.5 },
  { item: "juice", qty: 3, price: 2 },
];

const byItem = Object.groupBy(orders, ({ item }) => item);
for (const [item, rows] of Object.entries(byItem)) {
  const total = rows.reduce((sum, { qty, price }) => sum + qty * price, 0);
  console.log(`${item.padEnd(6)}${total.toFixed(2)}`);
}

async function grandTotal() {
  const lines = await Promise.all(orders.map(async (o) => o.qty * o.price));
  const sum = lines.reduce((a, b) => a + b);
  console.log("total", sum);
}

grandTotal();
console.log("the script ends here");
```

```output for=orders
tea   10.50
cake  4.25
juice 6.00
the script ends here
total 20.75
```

`Object.groupBy` makes a property for each key in the order in which it first sees the key.[^7] String keys keep the order of their creation, so `tea` is first.[^8] The line "total" comes last because `await` suspends the function.[^9] The rest of the function runs later as a job, and a job starts only when no other code runs.[^10]

## The language at a glance

A source file has the extension `.js`. Node.js reads a `.mjs` file as an ECMAScript module and a `.cjs` file as a CommonJS module. For a `.js` file, the `"type"` field of the nearest `package.json` decides, and without the field Node.js looks at the syntax.[^11] GitHub Linguist also counts `.jsx` files as JavaScript.[^12]

**Types.** The language has eight types: Undefined, Null, Boolean, String, Symbol, Number, BigInt and Object.[^13] A variable has no declared type, and a later assignment can give it a value of another type.[^5] The `+` operator joins strings when one operand is a string, and the other arithmetic operators convert strings to numbers ([[type-conversion]]).[^14] The `==` operator converts its operands before it compares them, and `===` does not.[^15] A Number is an IEEE 754-2019 double-precision value.[^16] A BigInt is an integer of any size, and an operator that mixes a BigInt and a Number throws a `TypeError`.[^14]

```javascript run id=types
let x = 1;
console.log(typeof x);
x = "one";
console.log(typeof x);
console.log(1 + "2", 1 - "2");
console.log(0 == "", 0 === "");
console.log(0.1 + 0.2);
console.log(2 ** 53 + 1, 2n ** 53n + 1n);
console.log(typeof null);
try {
  console.log(1n + 1);
} catch (err) {
  console.log(err.constructor.name, err.message);
}
```

```output for=types
number
string
12 -1
true false
0.30000000000000004
9007199254740992 9007199254740993n
object
TypeError Cannot mix BigInt and other types, use explicit conversions
```

`typeof null` gives `"object"` ([[null-references]]).[^17] Type errors appear only when the code runs, as the `TypeError` above shows ([[static-and-dynamic-typing]]).[^14]

**Memory.** A program never frees memory by hand. The standard does not guarantee that any object will be garbage collected.[^18] V8 has a "stop-the-world, generational, accurate garbage collector" ([[garbage-collection]]).[^19]

**Execution.** V8 has an interpreter called Ignition, which is register-based.[^20] TurboFan is one of the optimizing compilers of V8.[^21] An agent has one executing thread, and only one job runs at a time in an agent.[^22] Node.js enters an event loop after it runs the input script, and it exits when no callbacks are left.[^3]

**Paradigms.** Objects inherit properties through a prototype chain, and the `class` syntax builds on constructors and prototypes ([[subtyping]]).[^23] Functions are values, so a function can take and return other functions ([[higher-order-functions]], [[closures]]).[^4] Promises support asynchronous programming, and `async` functions give a syntax for functions that return promises ([[async-await]]).[^6]

## History and influence

Brendan Eich wrote the first implementation, called Mocha, in ten days in May 1995 at Netscape.[^4] The language appeared in public as LiveScript in the first beta of Netscape Navigator 2.0 in September 1995. Netscape and Sun announced the name JavaScript on December 4, 1995.[^52] The standard is based on several technologies, mainly JavaScript of Netscape and JScript of Microsoft.[^6] TC39 met for the first time on November 21 and 22, 1996.[^53] Sun held the trademark "JavaScript", so the standard got the name ECMAScript.[^53]

| Date | Event |
|---|---|
| March 1996 | Navigator 2.0 with JavaScript 1.0[^52] |
| June 1997 | the first edition of ECMA-262[^6] |
| December 1999 | the third edition, with regular expressions and `try` and `catch`[^6] |
| December 2009 | the fifth edition, with JSON support and strict mode[^6] |
| June 2015 | the sixth edition (ES2015), with modules, classes, block scoping and promises[^6] |
| June 2016 | ES2016, the first edition of the yearly cadence[^6][^25] |

Work on a fourth edition stopped, and that edition was never published.[^6] Ecma TC39 decides the changes today. A proposal moves through the stages 0, 1, 2, 2.7, 3 and 4, and the committee decides each step by consensus.[^24] Stage 4 needs two compatible implementations that pass the Test262 tests.[^24]

The statement syntax follows C, and the `for`-`in` statement comes from AWK.[^52] The syntax "intentionally resembles Java syntax".[^5] The prototype objects follow Self, and the first-class functions support idioms from Scheme.[^4]

## Coming from another language

- `==` converts its operands, so `0 == ""` is `true`. Use `===` to compare with no conversion ([[type-conversion]]).[^15]
- `sort` with no comparator converts the elements to strings, so `[10, 9, 1].sort()` gives `[1, 10, 9]`.[^54]
- An arrow function does not define its own `this`, `arguments`, `super` or `new.target`.[^55]
- `let` and `const` are scoped to the block, and `var` is scoped to the function ([[closures]]).[^56][^57]
- There are two empty values, `undefined` and `null`, and `typeof null` is `"object"` ([[null-references]]).[^17]
- All Number values are floating-point values, so integers are exact only up to a magnitude of 2 to the power 53. Use BigInt for larger integers ([[integer-overflow]]).[^16]
