This area covers programming for a special field. Each sub-area holds the languages, tools and pitfalls that a programmer meets in that field.

## What it holds

- Spreadsheets and formula languages: formulas, named ranges and the errors of spreadsheet programs.
- Financial programming: financial programming, money and its rules.
- Bioinformatics programming: programming for biology.
- Smart contracts: programs that run on a blockchain, and their languages and failures.
- Robotics: robotics programming, such as ROS.
- Automation and scripting: scripts that automate daily work.
- Education languages: languages for teaching, such as Scratch and Logo.
- Creative coding: code for art and music.

## What it does not hold

- The science of each field. It is out of scope.
- Data science. It is in [Data science and ML programming](/data-science-and-ml-programming/).
- Shell scripting as a language. It has a guide under [Languages](/languages/).
