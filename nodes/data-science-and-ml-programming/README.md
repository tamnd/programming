This area covers the tools that data scientists and ML engineers program with. It is about the code: notebooks, dataframes, arrays, plots, ML frameworks and pipelines. The theory of learning is not here.

## What it holds

- Notebooks: notebooks, such as Jupyter, and their pitfalls.
- Dataframes: dataframe libraries, such as pandas and Polars.
- Array programming libraries: NumPy and other array libraries.
- Plotting libraries: libraries that draw charts from data, such as Matplotlib.
- ML frameworks: PyTorch, JAX, TensorFlow and other frameworks as programming tools.
- Data pipelines: pipelines that move and transform data.
- Reproducibility: making a data analysis give the same result again.

## What it does not hold

- Machine learning theory and statistics. This site links out for them.
- Learning algorithms as algorithms. They are on [the algorithm site](https://algorithm.tamnd.com/).
- Array programming as a paradigm. It is in [Paradigms](/paradigms/).
- Programming with code models. It is in [AI-assisted programming](/ai-assisted-programming/).
