This area covers programming with language models and coding agents. It holds the tools, the ways to work with them, how to check what they write, and the questions of licence and provenance. This site is itself written with such tools, and its pages say so.

## What it holds

- **LLM basics for programmers.** What a programmer must know about language models to use them for code, without the inner workings.
- **Code completion.** Suggestions from a model as the programmer types, and the editors that give them.
- **Coding agents.** Agents that read, write and run code in a loop with tools.
- **Agent workflows.** How people organize work with agents: plans, parallel agents, review gates and the place of agents in a team.
- **Prompting for code.** How to ask a model for code and get a useful answer.
- **Tool use and MCP.** How a model calls tools, the Model Context Protocol, and the security of tools.
- **Evaluation of generated code.** How code models and tools are measured.
- **Review of AI-written code.** How to review, test and accept code that a model wrote.
- **Licensing and provenance of generated code.** The licence, origin and disclosure of generated code.

## What it does not hold

- How language models work inside. This site links out for it.
- ML frameworks as tools. They are in [Data science and ML programming](/data-science-and-ml-programming/).
- Code review in general. It is in [Construction practice](/construction-practice/).
