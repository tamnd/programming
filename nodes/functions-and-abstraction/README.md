This area covers the ways to give a part of a program a name and hide its detail. The main tools are functions, closures and modules. The area also holds the advanced forms of control that functions make possible, such as generators and continuations.

## What it holds

- Functions and procedures: defining and calling functions, return values and procedures with no result.
- Parameters and arguments: passing by value, by reference and by name, default arguments, keyword arguments and variadic functions.
- Recursion and tail calls: functions that call themselves, the call stack, and tail call optimization.
- First-class and higher-order functions: functions that are values, and functions that take or return functions.
- Closures and scope: functions that capture the variables of their scope.
- Currying and partial application: making a function of many arguments from functions of fewer.
- Lazy evaluation: evaluation that waits until a value is needed.
- Continuations: the rest of a computation as a value, and the control forms built on it.
- Generators and coroutines: functions that pause and resume, iterators and coroutines.
- Modules and namespaces: units of code with their own names, imports and exports.
- Information hiding: interfaces that hide the decisions that are likely to change.

## What it does not hold

- Async functions and event loops. They are in [Concurrency and parallelism](/concurrency-and-parallelism/).
- Package managers and the distribution of modules. They are in [Tools and workflow](/tools-and-workflow/).
- Methods and classes. They are in [Objects and classes](/objects-and-classes/).
- Recursive algorithms as algorithms, such as merge sort. They are on [the algorithm site](https://algorithm.tamnd.com/).
