This area covers programs that draw images and play sound, and the structure of games. It holds graphics APIs, shaders, game loops, engines and audio.

## What it holds

- Graphics APIs: OpenGL, Vulkan, Metal, Direct3D and WebGPU.
- Shaders and shading languages: programs that run on the GPU for each vertex or pixel, and the languages for them.
- Game loops: the game loop and fixed and variable time steps.
- Game engines: game engines as programming environments.
- Audio programming: programs that make and process sound.

## What it does not hold

- Computer graphics algorithms, such as ray tracing as an algorithm. They are on [the algorithm site](https://algorithm.tamnd.com/).
- GPU computing for data. It is in [Concurrency and parallelism](/concurrency-and-parallelism/) and [Scientific and high-performance computing](/scientific-and-hpc/).
- Game design. It is out of scope.
