This area covers numerical programs and programs that run on large machines. It holds the numerical languages, the parallel models of HPC, accelerators, numerical pitfalls and reproducible science.

## What it holds

- Numerical languages: Fortran, Julia and other numerical languages.
- MPI: the Message Passing Interface.
- OpenMP: directives that split loops between threads on one machine.
- CUDA and other accelerators: CUDA, HIP and SYCL, and how to move work to an accelerator.
- Numerical pitfalls: rounding, cancellation and other numerical errors in code.
- Reproducible scientific software: scientific software that gives the same result again.

## What it does not hold

- Numerical analysis as mathematics. This site links out for it.
- Numerical algorithms, such as FFT as an algorithm. They are on [the algorithm site](https://algorithm.tamnd.com/).
- Floating point as a machine format. It is in [Foundations](/foundations/).
