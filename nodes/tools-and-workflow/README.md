This area covers the tools that programmers use each day and how they fit into a workflow. It goes from the shell and the editor to version control, builds, packages and continuous integration.

## What it holds

- The shell and the command line: the command line, shell scripts and the common Unix tools.
- Editors and IDEs: text editors and integrated development environments.
- Version control: version control, and Git in depth.
- Build systems: Make, CMake, Bazel, Gradle and the other build tools.
- Package managers and dependencies: package managers, dependency resolution and lock files.
- Continuous integration and delivery: pipelines that build, test and ship each change.
- Containers for developers: containers as a developer tool.
- Documentation tools: tools that make documentation from code.
- Code search: tools to search and navigate large code bases.
- Dotfiles and environment management: toolchain versions, virtual environments and dotfiles.

## What it does not hold

- Kubernetes and container platforms for running services. They are in [Distributed and cloud programming](/distributed-and-cloud/).
- Supply-chain security of packages. It is in [Secure programming](/security/).
- The shell language as a language. It has a guide under [Languages](/languages/).
- Analyzers and linters. They are in [Program analysis and verification](/program-analysis-and-verification/).
