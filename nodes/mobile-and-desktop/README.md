This area covers apps for phones and for desktop computers. It holds the platforms, the GUI toolkits, the models of UI programming and how apps are packaged and shipped.

## What it holds

- Android: programming for Android.
- iOS: programming for iOS.
- Cross-platform frameworks: frameworks that target more than one platform.
- Desktop GUI toolkits: Qt, GTK, WinUI and the other toolkits for desktop apps.
- UI programming models: immediate, retained and declarative UI models.
- App packaging and distribution: packaging apps and shipping them through stores and installers.

## What it does not hold

- Web apps in a browser. They are in [Web development](/web-development/).
- The languages of the platforms, such as Kotlin and Swift. They have guides under [Languages](/languages/).
- UI design as a visual subject. It is out of scope.
