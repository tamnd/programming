This area covers apps for phones and for desktop computers. It holds the platforms, the GUI toolkits, the models of UI programming and how apps are packaged and shipped.

## What it holds

- **UI programming models.** The models that all GUI frameworks share: event loops, retained and immediate mode, declarative UIs, layout and data binding. This sub-area comes first, because the platform sub-areas use its terms.
- **Android.** The Android platform, its app model and its tools.
- **iOS and Apple platforms.** iOS, iPadOS and the other Apple platforms, their app model and their tools.
- **App platform services.** The device services that mobile and desktop apps use on all platforms: notifications, local storage, deep links, sensors and connectivity.
- **Cross-platform frameworks.** Frameworks that build apps for many platforms from one code base.
- **Desktop GUI toolkits.** The GUI toolkits of Windows, macOS and Linux, and the toolkits that run on all three.
- **App architecture and quality.** The structure of a mobile or desktop app across platforms: navigation, dependency injection, modules, performance and app security.
- **App packaging and distribution.** How to build, sign, ship and update mobile and desktop apps.

## What it does not hold

- Web apps in a browser. They are in [Web development](/web-development/).
- The languages of the platforms, such as Kotlin and Swift. They have guides under [Languages](/languages/).
- UI design as a visual subject. It is out of scope.
