```python run id=mixin-parts
class OrderData:  # one part, for example generated by a tool
    def __init__(self, count, price):
        self.count = count
        self.price = price


class OrderPricing:  # another part, written by hand
    def total(self):
        return self.count * self.price


class Order(OrderData, OrderPricing):  # the class that code uses
    pass


o = Order(3, 40)
print(o.total(), [c.__name__ for c in Order.__mro__])
```

```output for=mixin-parts
120 ['Order', 'OrderData', 'OrderPricing', 'object']
```

- Verdict: absent. A class statement makes the whole class at once. Base classes are the usual way to keep parts of a class in separate modules.
- `Order` gets `__init__` from `OrderData` and `total` from `OrderPricing`, in the order that `__mro__` shows. Unlike C# parts, each part is a class of its own, so a part can be used in other classes too.
